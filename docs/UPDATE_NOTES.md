# 업데이트 노트

이 파일은 Lighthouse AMC 대시보드의 기능 변경, 제거, 보류 사항을 기록합니다. 앞으로 대시보드 기능을 추가하거나 수정한 뒤에는 제가 이 노트를 함께 갱신합니다.

## 2026-07-01

### 부팅 자동 실행
- Windows 로그인 시 GitHub의 최신 내용을 먼저 받은 뒤 로컬 서버를 실행하는 `scripts/start-dashboard.ps1`을 추가했습니다.
- 작업 스케줄러에 자동 실행을 등록하는 `scripts/install-startup-task.ps1`과 해제용 `scripts/uninstall-startup-task.ps1`을 추가했습니다.
- 간단히 수동 실행할 수 있는 `start-dashboard.bat`을 추가했습니다.
- 자동 실행 로그를 `logs/startup.log`에 남기고, `logs/`는 GitHub에 올리지 않도록 설정했습니다.
- Windows PowerShell 5.1에서 `git`/`npm`의 정상 진행 메시지(stderr)가 치명적 오류로 처리되어 자동 실행이 중단되던 문제를 수정했습니다. 네이티브 명령을 `cmd /c`로 감싸 로그 파일로 안전하게 기록하도록 변경했습니다.

### 헤게모니 국면 분류
- KOSPI/KOSDAQ 전 종목을 매출액·영업이익 YoY 기준으로 4국면(1국면 턴어라운드 / 2국면 헤게모니 / 3국면 헤게모니 상실 감지 / 4국면 실적 하락)으로 분류하는 `phase.html` 화면을 추가했습니다.
- 동부증권 '투자의 정석 — 헤게모니에 투자하라' 분류 기준을 적용했고, 기존 ai_agent 프로젝트의 검증된 분류 로직을 재사용했습니다.
- 국면별 요약 카드, 종목명·코드 검색, 국면 필터, 컬럼 정렬(시가총액·매출 YoY·영업이익 YoY·영업이익률)을 제공합니다.
- 대시보드 라이트/다크 테마에 맞춰 화면을 새로 구성하고, 사이드바에 '국면 분류' 메뉴를 추가했습니다.
- 60일 수익률 항목은 새 대시보드에서는 제외했습니다.
- 502MB 재무 DB를 GitHub에 올리지 않기 위해, 분류 결과를 약 600KB JSON 스냅샷(`data/phase-classification.json`)으로 커밋해 모든 PC가 동일한 데이터를 사용하도록 했습니다.
- 스냅샷은 financial.db가 있는 PC에서 `scripts/generate-phase-data.py`로 생성하며, 분기 재무가 갱신되면 다시 생성해 커밋합니다.
- `server.js`에 `/api/phase` 엔드포인트를 추가했습니다. 추후 재무 DB가 온라인으로 이전되면 이 엔드포인트 내부만 교체하면 화면은 그대로 동작합니다.
- 투자의 정석(국면 분류) 페이지 우측 상단에 마지막 업데이트 일자를 표시하고, 그 옆에 새로고침 버튼을 추가했습니다. 새로고침을 누르면 서버가 스냅샷 생성기를 다시 실행해 시가총액 등 데이터를 재계산합니다(financial.db·Python 이 있는 PC에서 동작, 수십 초 소요). `server.js`에 `POST /api/phase/refresh` 엔드포인트를 추가했습니다.

### 뉴스플로우
- '뉴스플로우' 탭과 페이지(`news.html`)를 새로 추가했습니다. 뉴스원별로 카드(테이블) 형태로 구분하고, 각 기사는 제목 밑에 링크가 붙는 형태로 한 줄씩 표시합니다. 뉴스원마다 수집 방식(RSS·크롤) 배지와 건수를 함께 보여줍니다.
- 뉴스 수집은 RSS와 크롤링 2가지로 계획되어 있으며, 현재 단계에서는 수집을 연결하지 않았습니다. 화면 상단에 '수집 미연결' 안내 배너를 표시하고, 표시 형식 확인용 예시 데이터(`data/news-flow.json`)로 렌더링합니다. `server.js`에 `/api/news` 엔드포인트를 추가했습니다.
- (기존 텔레그램 뉴스 봇 연결은 이후 단계에서 진행합니다.)
- 각 뉴스원 테이블은 최대 20줄까지 표시하고, 초과하면 카드 내부에서 스크롤해 볼 수 있도록 했습니다(제목 줄바꿈에 따라 줄 높이가 달라져도 20번째 줄까지 정확히 보이도록 높이를 계산).
- 뉴스 수집을 실제로 연결했습니다. 기존 텔레그램 뉴스 봇의 소스 목록을 재사용하는 독립 모듈 `modules/news-flow/collect.py`를 추가했습니다. RSS는 봇의 `dynamic_feeds.json`(약 49개 피드)을 feedparser로 수집하고, 크롤은 봇의 `scraper.py`(더벨·한국금융신문·딜사이트·IR협의회 등)를 그대로 재사용합니다. Playwright 기반 JS 소스는 이번 단계에서 제외했습니다.
- 수집 결과는 `data/news-flow.json` 스냅샷으로 저장하고 `/api/news`로 서빙합니다. 뉴스플로우 페이지 우측 상단에 소스·건수·업데이트 시각과 새로고침 버튼을 추가했으며, 새로고침을 누르면 서버가 수집기를 다시 실행합니다(`POST /api/news/refresh`). 현재 약 58개 소스·1,300여 건을 수집합니다.
- 전 종목이 세로로 모두 펼쳐져 화면이 지나치게 길어지던 문제를 개선했습니다. 테이블을 높이가 제한된 스크롤 영역(헤더 고정)으로 감싸고 행 간격을 조밀하게 조정해 더 콤팩트하게 만들었습니다.
- 사이드바 메뉴를 '홈'과 '투자의 정석 (동부)' 두 항목으로 정리했습니다. 기존 '국면 분류' 메뉴 명칭을 '투자의 정석 (동부)'로 변경하고, 비어 있던 '설정' 탭은 제거했습니다.
- 사이드바 상단에 이미 로고와 대시보드 이름이 있어, 내용 페이지 상단바(topbar)의 중복 로고 이미지를 제거했습니다. 홈 화면 상단 제목은 대시보드 이름('Lighthouse AMC') 대신 '홈'으로 변경했습니다.

### 전자·닉스 비중 체크
- 삼성전자·SK하이닉스의 시가총액 비중(%) 최근 24개월 동향을 테이블로 보여주는 '전자, 닉스 비중 체크' 탭을 추가했습니다.
- 금융투자협회(KOFIA) 월간 '시가총액 비중안내' 공지의 PDF에서 비중을 파싱합니다(데이터: 코스콤). 삼성전자는 보통주·우선주·합계(A+B), SK하이닉스는 보통주 비중을 표시하고 전월 대비 증감(%p)을 함께 보여줍니다.
- SK하이닉스는 별도 안내 대상이 된 2025년 10월부터 제공되어, 그 이전 달은 해당 없음(–)으로 표시합니다.
- 수집·파싱 로직은 대시보드 본체와 분리해 독립 모듈 `modules/weight-check/`로 구현했습니다(GitHub 별도 관리 목적). 결과는 `data/weight-check.json` 스냅샷으로 커밋해 모든 PC가 재수집 없이 동일하게 사용하며, `server.js`의 `/api/weight`로 서빙합니다.

- 대시보드 하단에 업데이트 노트 패널을 추가했습니다.
- 패널은 `docs/UPDATE_NOTES.md`를 읽어 최근 날짜별 변경 사항을 표시합니다.
- 업데이트 노트 표시 방식을 접이식 목록으로 변경했습니다.

- 업데이트 노트 표시 개수를 최근 10개로 확장했습니다.
- 항목이 많아질 때 테이블 내부에서 스크롤해 볼 수 있도록 구성했습니다.
- 앞으로 기능을 추가하거나 제거할 때 이 노트를 제가 함께 갱신합니다.
