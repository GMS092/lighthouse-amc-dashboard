이 파일은 Lighthouse AMC 대시보드의 기능 변경, 제거, 보류 사항을 기록합니다. 앞으로 대시보드 기능을 추가하거나 수정한 뒤에는 제가 이 노트를 함께 갱신합니다.

### 상대수익률 매일 자동 갱신 (퀀티와이즈)
- 상대수익률 차트 데이터를 매일 자동으로 갱신하도록 자동화했습니다. `scripts/refresh-relative.ps1`이 Excel을 열어 퀀티와이즈 리본의 'Book'(워크북 새로고침)을 클릭하고, 로그인 창이 뜨면 저장된 자격증명으로 로그인 버튼을 눌러 로그인합니다(공용 ID 중복 로그인 대화상자가 뜨면 강제 로그인으로 처리). 새로고침이 끝나면 저장 → `collect.py`로 `data/relative-return.json` 재생성 → 커밋·푸시하고, GitHub Pages가 자동 배포됩니다.
- `scripts/register-relative-refresh-task.ps1`로 매일 오전 6시 실행되는 작업 스케줄러 작업을 등록합니다(로그온 세션에서 실행 — 6시에 PC가 켜져 로그인·잠금 해제 상태여야 GUI 자동화가 동작). 해제는 `-Unregister` 옵션.
- 비밀번호는 코드/파일에 저장하지 않습니다. 퀀티와이즈에 이미 저장된 자격증명이 채워진 로그인 창에서 로그인 버튼만 클릭합니다.
- 수집기가 장중/장전에 비어 있는 오늘 행을 건너뛰고 '실제 데이터가 있는 마지막 날짜'를 기준일로 잡도록 수정했습니다(6시 실행 시 전일 종가 기준으로 그려짐).

- 각 뉴스원 테이블은 최대 20줄까지 표시하고, 초과하면 카드 내부에서 스크롤해 볼 수 있도록 했습니다(제목 줄바꿈에 따라 줄 높이가 달라져도 20번째 줄까지 정확히 보이도록 높이를 계산).
- 뉴스 수집을 실제로 연결했습니다. 기존 텔레그램 뉴스 봇의 소스 목록을 재사용하는 독립 모듈 `modules/news-flow/collect.py`를 추가했습니다. RSS는 봇의 `dynamic_feeds.json`(약 49개 피드)을 feedparser로 수집하고, 크롤은 봇의 `scraper.py`(더벨·한국금융신문·딜사이트·IR협의회 등)를 그대로 재사용합니다. Playwright 기반 JS 소스는 이번 단계에서 제외했습니다.
- 수집 결과는 `data/news-flow.json` 스냅샷으로 저장하고 `/api/news`로 서빙합니다. 뉴스플로우 페이지 우측 상단에 소스·건수·업데이트 시각과 새로고침 버튼을 추가했으며, 새로고침을 누르면 서버가 수집기를 다시 실행합니다(`POST /api/news/refresh`). 현재 약 58개 소스·1,300여 건을 수집합니다.
- 소스가 많아 페이지가 지나치게 길어지던 문제를 개선했습니다. 뉴스원 카드의 노출 줄 수를 20줄에서 6줄로 줄여(초과분은 카드 내부 스크롤) 컴팩트하게 만들고, 격자 열을 조금 더 조밀하게 조정했습니다.
- 전 종목이 세로로 모두 펼쳐져 화면이 지나치게 길어지던 문제를 개선했습니다. 테이블을 높이가 제한된 스크롤 영역(헤더 고정)으로 감싸고 행 간격을 조밀하게 조정해 더 콤팩트하게 만들었습니다.
- 사이드바 메뉴를 '홈'과 '투자의 정석 (동부)' 두 항목으로 정리했습니다. 기존 '국면 분류' 메뉴 명칭을 '투자의 정석 (동부)'로 변경하고, 비어 있던 '설정' 탭은 제거했습니다.
- 사이드바 상단에 이미 로고와 대시보드 이름이 있어, 내용 페이지 상단바(topbar)의 중복 로고 이미지를 제거했습니다. 홈 화면 상단 제목은 대시보드 이름('Lighthouse AMC') 대신 '홈'으로 변경했습니다.

### 전자·닉스 비중 체크
- 삼성전자·SK하이닉스의 시가총액 비중(%) 최근 24개월 동향을 테이블로 보여주는 '전자, 닉스 비중 체크' 탭을 추가했습니다.
- 금융투자협회(KOFIA) 월간 '시가총액 비중안내' 공지의 PDF에서 비중을 파싱합니다(데이터: 코스콤). 삼성전자는 보통주·우선주·합계(A+B), SK하이닉스는 보통주 비중을 표시하고 전월 대비 증감(%p)을 함께 보여줍니다.
- SK하이닉스는 별도 안내 대상이 된 2025년 10월부터 제공되어, 그 이전 달은 해당 없음(–)으로 표시합니다.
- 수집·파싱 로직은 대시보드 본체와 분리해 독립 모듈 `modules/weight-check/`로 구현했습니다(GitHub 별도 관리 목적). 결과는 `data/weight-check.json` 스냅샷으로 커밋해 모든 PC가 재수집 없이 동일하게 사용하며, `server.js`의 `/api/weight`로 서빙합니다.
